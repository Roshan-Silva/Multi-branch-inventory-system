# Multi-Branch Inventory & Procurement Management System

A production-style inventory and procurement management platform designed
for organizations operating across multiple branches.

## Tech Stack

### Backend
- ASP.NET Core Web API
- .NET 10
- C#

### Frontend
- React
- TypeScript
- Vite

### Database
- PostgreSQL (planned)

## Architecture

The backend follows a layered architecture consisting of:

- Domain
- Application
- Infrastructure
- API

## Planned Features

- User authentication
- Role-based authorization
- Branch management
- Product and category management
- Supplier management
- Branch inventory
- Purchase requests
- Purchase orders
- Approval workflows
- Goods Received Notes
- Stock transfers
- Inventory transaction history
- Audit logging
- Reporting and dashboards
- Docker
- CI/CD
